How to read these numbers

All values in this preview are illustrative. Sightings are stored recognition events after the application's existing suppression rules; they are not confirmed visits, vehicle movements or traffic totals. Different plate strings may belong to the same vehicle. Relay commands do not confirm a physical gate opening. A production version must count actual command outcomes, including manual commands, before showing this metric. Comparisons use equal elapsed periods; today is not compared with a complete previous day. No confidence or allowlist percentage is presented as recognition accuracy.
